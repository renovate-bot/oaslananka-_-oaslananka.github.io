# Security Policy

## Supported Versions

This is a personal portfolio website. The latest deployment is always the
supported version.

| Version       | Supported |
| ------------- | --------- |
| Latest (main) | Yes       |
| Previous      | No        |

## Reporting a Vulnerability

If you discover a security vulnerability, please do not open a public issue.

Instead, report it privately via:

- GitHub Security Advisories:
  [Report a vulnerability](https://github.com/oaslananka/oaslananka.github.io/security/advisories/new)
- Email: See the profile contact page at
  [oaslananka.dev/contact](https://oaslananka.dev/contact)

Please include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact

I aim to respond within 72 hours and will keep you informed of the resolution.
